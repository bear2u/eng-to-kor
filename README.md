# 키바꿈

React로 만든 한글 → 영문 두벌식 자판 변환기입니다. 발음에 따른 로마자 표기가 아니라 같은 위치의 영문 키로 변환합니다.

- `한글q12` → `gksrmfq12`
- 영문·숫자·기호·공백·줄바꿈은 그대로 유지
- 완성형 한글, 단독 자모, 분해된 현대 한글 자모 지원
- 실시간 변환, 결과 복사, 지우기, 예제 입력, 모바일 화면 지원
- 사용자 입력을 저장하거나 서버로 전송하지 않음

## 실행

Node.js 22.12 이상을 권장합니다.

```sh
npm install
npm run dev
```

표시되는 로컬 주소로 접속합니다.

```sh
npm test
npm run build
npm run preview
```

배포 파일은 `dist/`에 생성되며 정적 웹 호스팅에 올릴 수 있습니다. 클립보드 복사는 HTTPS 또는 localhost 환경에서 지원됩니다. 자동 복사가 실패하면 결과를 선택해 수동 복사할 수 있도록 안내합니다.
